# ADARVIX Technologies Website

A responsive, dark premium-style static website built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — layout, colours, responsive styling and animations
- `script.js` — mobile navigation, active navigation state, current year and contact form mailto behaviour

## Run locally
1. Keep all three files in the same folder.
2. Double-click `index.html` to open it in a browser.
3. For a better development workflow, open the folder in VS Code and use the Live Server extension.

## Contact form note
This is a static website. The enquiry form validates the fields and opens the visitor's default email app with a pre-filled message addressed to `adarvix.tech@gmail.com`. It does not store or send enquiries through a server. A backend or form service is needed for direct website submissions.

## Before publishing
- Confirm `adarvix.tech@gmail.com` is active and accessible.
- Replace the School Connect concept text/image if you later add a real project. The current concept uses fictional sample information and is clearly labelled.
- Add your actual social links only after creating those accounts.
- Test on mobile and desktop.
